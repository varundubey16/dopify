D. How to google sign up in django?

Navigate to APIs & Services then Credentials
click on Create Credentials then OAuth client ID.
Select Web application as the application type.
Add your authorized redirect URIs, i used localhost when running on laptop, so it might be like http://localhost:8000/accounts/google/login/callback/. this is default for running on backend loscalhosts
OAuth client ID and secret
add in the secret.json
